# EquiPay Buddy 💰

EquiPay Buddy is a modern, feature-rich expense splitting application designed for friends, roommates, and travelers. With a sleek glassmorphism-inspired UI and powerful automated features, managing shared finances has never been easier.

![EquiPay Banner](/src/assets/mainlogo2.png)
[Live Demo](https://equipay-buddy.vercel.app/)  

## ✨ Features

- **Group Management**: Create groups for trips, households, or events.
- **Smart Splitting**: Split expenses equally, by exact amounts, or by percentages.
- **Deep Insights**: Get smart analytics and tips on your spending habits.
- **Debt Simplification**: Automatically minimize the number of transactions needed to settle up.
- **International Support**: Real-time currency conversion for world travelers.
- **Unified Settlements**: Record payments via UPI or Cash with ease.
- **Instant Notifications**: Stay updated on group activity and new expenses.
- **Premium UI**: Experience a stunning, responsive design with full dark mode support.

## 🚀 Tech Stack

- **Frontend**: [React.js](https://reactjs.org/) with [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & [Shadcn UI](https://ui.shadcn.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Backend/Database**: [Supabase](https://supabase.com/) (PostgreSQL & Auth)
- **State Management**: [TanStack Query](https://tanstack.com/query/latest) (React Query)
- **Icons**: [Lucide React](https://lucide.dev/)
